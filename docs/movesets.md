# Movesets and fighting styles

Generated by `python tools/bdkit.py style-map ISO/SLUS_211.50 ISO/XAF/CDATA.XAF > docs/movesets.md`. Do not edit by hand; add notes to README.md instead.

Button legend for the inputs: **P** punch, **K** kick, **G** guard, **A** action button (grab, search, pick up), arrows are directions relative to the fighter, `/` separates alternatives. The game's own glyphs are 〆 P, ◎ K, ◇ G, 4 A; a few rare ones (▽, ∫, ★) are left as they are.

## Where this comes from

- Fighter rows: class table `0x0050D6A0` (`{body, style, skeleton, groups}`).
- Move lists: table at `0x005CAB40`, 8 bytes per style, row = style - 1: `{u16 first input text, u16 last input text, u16 first name text, u16 last name text}`. Read by `0x001C5C30` (input text) and `0x001C5C00` (name text), which call the text lookup `0x00387980`.
- Text: CDATA.XAF entry 398 (English; JP 397, FR 399, DE 400, ES 401, IT 402). Inputs are IDs 0x9C40-0xA0F3, names 0xAFC8-0xB47B, one pair per move.
- These are the in-game MOVE LIST screens, so the order is the menu order. Which animation each move plays is not mapped yet (that's the still-missing command table).

## Which swaps work

`swap-moveset A B` copies B's style and group list into A's row, so it is clean only when A and B have the same body size. Across body sizes use `--keep-body`, which keeps A's body groups and swaps only the style groups (tested for M getting L moves: Aaron with Jason G's moveset).

- **Body S** (12): plain swap among BOXER_S, GRAPPLER_S, KNUCKLEMASTER_S, JUGGLER_S, KICKBOXER_S, STRIDER_S, WEAPONMASTER_S, NEGOTIATER_S, GANG_S, POLICE_S, GINA, TESTER_S.
- **Body M** (24): plain swap among BOXER_M, GRAPPLER_M, KNUCKLEMASTER_M, JUGGLER_M, KICKBOXER_M, STRIDER_M, WEAPONMASTER_M, NEGOTIATER_M, GANG_M, POLICE_M, PERFECT, FATIMA, AARON, RAVEN, LOLA, IGNACY, TESTER_M, EUGENE, ZANETTI, CARLO, MELVIN, WARREZ, TRACY, CHESTER.
- **Body L** (15): plain swap among BOXER_L, GRAPPLER_L, KNUCKLEMASTER_L, JUGGLER_L, KICKBOXER_L, STRIDER_L, WEAPONMASTER_L, NEGOTIATER_L, GANG_L, POLICE_L, GREGOLIO, JASON_G, QUINCY, TESTER_L, WENDEL.
- **Different body sizes**: always add `--keep-body`.
- `--keep-body` edits A's own group list in place. Each hero has a list of its own; the generic S/M/L rows have not been checked for shared lists, so look before using one of them as A.
- **Style 0x09** (TESTER S/M/L) has no entry in the move list table (0xFFFF).
- **PERFECT** is an M body with style 0x04 (Juggler's moves) whose list loads every generic style group and all three body groups. As a source it gives only the Juggler moves plus a much bigger load, so use JUGGLER_M instead.
- Style 0x0B's list has Pedigree and Canadian Destroyer and 0x12's has Stunner and Belly to Belly, matching the developers' leftover notes ("Glegoio" / "Jason" use them), which confirms row = style - 1.
- **Styles 0x1C-0x23** are short versions (5-9 moves) of the eight generic styles 0x01-0x08, and **0x25-0x2F** are weapon move lists (bladed, blunt, swinging, large, handgun, katana, shotgun). No fighter row uses them; they are probably picked at run time (unarmed recruits, weapons in hand).
